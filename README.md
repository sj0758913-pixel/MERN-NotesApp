# 📝 Personal Notes App

A simple full-stack Notes Application where users can create, view,
update and delete their personal notes.

🌐 **Live Website:** https://personal-noteapp.netlify.app/

## ✨ Features

- 🔐 User Registration & Login
- 📝 Create Notes
- 👀 View Notes
- ✏️ Edit Notes
- 🗑️ Delete Notes
- 📅 Note creation date
- ⏳ Loading animations
- ⚠️ Empty field validation
- 🔒 User-specific notes

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
